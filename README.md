# homeplate · AI 家电保养与维修助手

> 买家电是一瞬间的事，养家电是十几年的事——总得有个东西替你记着。

homeplate 是面向家庭、教室和办公室等空间的家电档案 Web 应用。第一版围绕拍铭牌建档、扫码查询、保修保养管理、主动提醒和 AI 故障初步排查展开，方便同一空间的人共同使用设备资料。

**存储方式**：使用 SQLite，通过 SQLAlchemy 访问，无需单独安装数据库服务或配置数据库账号密码。

## 第一版功能

一个空间共用一份档案，扫码即可查看，修改需要管理密码，不要求每个人注册账号。

| 模块 | 首版功能 |
|---|---|
| 空间共享档案 | 创建空间、生成查看二维码、管理密码与恢复、查看／管理权限分离、空间数据隔离 |
| AI 建档 | 拍照或相册识别铭牌，预填可修改，识别失败可手动填写 |
| 家电档案 | 设备列表与详情、新增、编辑、删除、铭牌照片留档 |
| 保修管理 | 根据购买日期和保修期计算到期日，展示剩余时间与状态 |
| 保养管理 | 按品类生成计划，支持调整，完成后自动安排下一期 |
| 首页 | 设备概况、待保养、即将过保和优先处理事项 |
| 基础保障 | 手机适配、访问保护、可靠保存、基础备份与恢复 |
| 主动提醒 | 保修临期、保养到期和逾期提醒，先接通一个推送渠道 |
| AI 助手 | 关联设备的文字多轮问答、自检步骤、专业维修建议和安全提示 |

以上是已确认的第一版目标范围。**当前进度**：已具备建档、档案、保修、保养和首页等主要流程，已完成 SQLite 切换及现有数据迁移，支持首次启动自动建表。空间共享、主动提醒、AI 助手及完整的备份恢复功能仍需补齐，九模块第一版尚未整体验收。

个人账号与成员管理、完整维修记录、费用统计、维修派单、批量建档、深色模式和小程序等暂不纳入第一版。

## 快速开始

环境要求：Python 3.12+，无需安装 MySQL。以下为 Windows 本地开发步骤，在项目根目录打开 PowerShell。

1. **安装依赖**

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

2. **按需配置环境变量**

   手动建档无需配置即可启动。需要铭牌识别或访问密码时，将 `.env.example` 复制为 `.env`；已有 `.env` 时直接修改，保留原有配置。

   - `DATABASE_URL`：可省略，默认 `sqlite:///data/homeplate.db`；相对路径以项目根目录为准。旧 MySQL 配置需先完成数据迁移，再改为 SQLite。
   - `AI_API_BASE`、`AI_API_KEY`、`VISION_MODEL`：使用铭牌识别时填写；未配置时仍可手动建档。
   - `ACCESS_PASSWORD`：按需设置整站访问密码；留空不启用保护。这是现有版本的访问方式，空间管理权限仍待实现。

3. **启动**

   ```powershell
   .\.venv\Scripts\python.exe run.py
   ```

   浏览器打开 [http://127.0.0.1:8001](http://127.0.0.1:8001)。若设置了访问密码，浏览器弹窗中的用户名可任意填写，密码使用 `ACCESS_PASSWORD` 的值。

首次启动自动创建数据库和缺失的数据表，重启保留现有记录。

| 数据位置 | 内容 |
|---|---|
| `data/homeplate.db` | 设备档案、保养任务 |
| `static/uploads/` | 铭牌照片 |
| `data/backups/` | 本机迁移备份，若有；不会在每次启动时自动备份 |

备份时先停止服务，再同时保存数据库文件和照片目录。`data/` 与上传照片均不进入 Git；迁移备份可能含旧配置，仅在本机保管。
