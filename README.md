# homeplate · AI 家电保养与维修助手

> 买家电是一瞬间的事，养家电是十几年的事——总得有个东西替你记着。

我们想做一个管"家电后半生"的小助手。冰箱、空调、净水器、洗衣机……买回家只是开始，保修、保养、维修，才是后面十几年的事。你只需要拍一张铭牌，剩下的交给它。

**目标用户**：需要管理家电、维修记录和保修期限的普通家庭。

## 现在的痛点

家里电器越买越多，可这几件事，几乎每个家庭都在反复吃亏：

**东西找不到。** 说明书塞进某个抽屉，保修卡不知道夹在哪本书里，发票早扔了。等到机器出问题才发现——凭证永远在需要的时候失踪。

**保修期靠猜。** 什么时候买的要翻订单回忆，保修几年要去查型号。很多人都是报修时才发现：已经过保了，就差那么一两个月。

**保养靠感觉。** 净水器滤芯要换、空调滤网要洗、热水器要保养……说明书都写着"定期维护"，可"定期"是多久？没人记得住。等到出了问题再保养，往往已经伤了机器。

**维修靠重来。** 上次是哪个师傅修的、换了什么零件、花了多少钱，全散在聊天记录里。下次再坏，只能从头打听；一台机器修过几次、还值不值得修，也说不清楚。

## 它要解决什么

一句话：把全屋家电的"后半生"管起来。

- **不用记**——拍一张铭牌，品牌、型号、序列号自动识别，档案自动建立
- **不用查**——保修期自动计算，维护计划自动排期
- **不用慌**——保修到期、滤芯更换、定期保养，提前提醒，而不是事后后悔
- **不用翻**——维修记录随手记，发票保修卡随时调

## 核心使用流程

**拍摄铭牌 → 识别型号 → 建立档案**，三步建起一台设备的完整档案；

然后系统**自动创建维护计划**，把保修期、滤芯更换、定期保养都排进日程；

最后靠**到期提醒**和**维修记录**两个轮子，让这套档案日常转起来。

## 功能设计

### 一、家电档案

- 拍一张设备铭牌，自动识别品牌、型号、序列号
- 补充购买日期、渠道、价格；发票、说明书拍照存档
- 全屋家电一张清单，每台设备一份独立档案

### 二、保修管理

- 按"购买日期 + 型号保修期"自动计算到期日
- 到期前分级提醒（30 天 / 7 天），不错过报修窗口
- 报修需要凭证时，发票保修卡随取随用

### 三、维护计划

- 按设备类型自动生成维护任务：净水器换滤芯、空调清洗滤网、冰箱除霜、洗衣机筒清洁……
- 周期可自定义；任务完成打勾，下一期自动排上

### 四、提醒中心

- 保修到期、滤芯更换、定期保养，所有该做的事集中在一处
- 到点提醒，不再靠人脑记

### 五、维修记录

- 每次维修记一笔：时间、故障、师傅、费用、更换零件
- 自动统计累计维修花费，帮判断"修还是换"
- 维修时把设备的"病历"给师傅看，沟通效率翻倍

### 六、AI 维修助手（后续规划）

- 描述故障现象，AI 给出常见原因和排查建议
- 结合设备档案与维修历史，给出更贴合的判断

## 第一版做什么

产品范围很清晰，第一版不需要训练模型——**OCR 识别 + 任务提醒 + 数据管理**就能构成有用的第一版：

- 拍摄铭牌 → 识别 → 建档，闭环跑通
- 保修期计算 + 到期提醒
- 维护计划与维修记录

第一版做出来就有真实用户：家里现成的电器，就是最好的测试数据。

## 实现思路（初步）

- **形态**：先做 Web / 小程序，手机拍照是核心入口
- **识别**：现成 OCR 服务读取铭牌文字，大模型结构化成"品牌 / 型号 / 序列号 / 日期"
- **数据**：设备档案、维护任务、维修记录的数据管理
- **提醒**：定时任务检查到期项，推送到手机

## 后续计划

- 家庭成员共享：一份档案，全家都能看、都能记
- AI 维修助手落地
- 耗材管理：滤芯什么时候买、买哪个型号，库存提醒
- 从"管理"到"决策"：换新时机建议、维修性价比判断
