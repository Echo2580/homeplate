# homeplate · 产品灵魂三问

> 用途：产品故事校验——三句话讲不清，就说明还没想清楚。
> 日期：2026-10-19 ｜ 依据：`jtbd-premortem-analysis.md`、`mvp.md`、`devlog.md`

---

## 0. 电梯版（30 秒）

> 家里有 5 台以上家电、负责买和修的那个人，最怕三年后家电坏了：发票找不到、保修说不清、保养全凭记忆。
> homeplate 让他拍一张铭牌，30 秒建好档案；保修剩多久、下次该保养什么，打开首页就知道。
> 它不解决「买家电」，只解决「养家电」。

---

## 1. 用户是谁？

**一句话：家里那个「管家电」的人——买、收票据、报修都归他。**

| 项 | 主用户：家庭设备管理员 | 辅用户：家庭共同使用者 |
|---|---|---|
| 是谁 | 25–40 岁，子女或业主 | 父母 / 配偶，50 岁以上 |
| 家庭 | 5–10 台家电，过去三年买过 2–3 台 | 同住，共用这批家电 |
| 现在怎么做 | 发票塞抽屉、照片存相册、周期靠记忆 | 直接问主用户 |
| 雇佣时刻 | 新家电进门、家电坏了、换季清洗、被家人问 | 想知道「过保没」「该洗没」 |
| 手机习惯 | 安卓，会拍照，不愿学新工具 | 只会微信/扫码，不愿注册 |

**典型画像**：家里 8 台家电，冰箱 3 年、空调 6 年、净水器刚换滤芯；发票和保修卡在电视柜第二个抽屉；手机里有个「家电」相册，但从来没整理过。买新家电时他愿意拍一张照，但不愿意填十个字段。

**第一版只服务这类家庭**：家电数量足够多、有人负责售后。2–3 台家电、坏了直接换新的家庭，不是第一版的目标。

---

## 2. 用户的痛苦是什么？

| 场景 | 现在怎么做 | 真实代价 |
|---|---|---|
| 新家电进门 | 师傅走后，发票、保修卡塞进抽屉 | 三年后坏了，翻遍抽屉找不到，只能自费 |
| 换季保养 | 想不起来上次洗滤网是什么时候 | 被售后电话一推销就下单，花冤枉钱 |
| 家人询问 | 父母问「冰箱过保没」，翻相册、翻抽屉 | 最后说「应该没过吧」，答案不可信 |
| 家电坏了 | 不知道保内保外，报型号也报不准 | 上门费、检测费、换件费，一笔糊涂账 |

**表面痛**：记不住发票、保修期、保养周期。

**深层痛**：关键时刻没有可信答案——要么花冤枉钱，要么在家人面前背锅。

**最扎心的一条**：不记也没事，直到出事。家电是低频任务，拖延没有即时代价，所以用户永远不会主动开始。这也是项目最可能失败的地方——不是功能不好用，是「不打开也不觉得亏」。

**不是臆想**：devlog 里真实记录过——设备名识别不出，用户起了「2」「6」这种名字；品类不够用；保养计划不能改。上线三天，库里只有 2 台，家人没有自助查过一次。

---

## 3. 产品如何解决？

**一句话价值：拍一张家电铭牌，30 秒建好档案；保修剩多久、下次该保养什么，打开首页就知道。**

| 痛苦 | 产品动作 | 用户得到什么 |
|---|---|---|
| 找不到发票、型号 | 拍铭牌 → AI 读出品牌/型号/序列号/品类 → 照片留档 | 档案永远在手机里，不用翻抽屉 |
| 猜保修 | 购买日期 + 保修期 → 自动算到期日 → 三色状态 | 一眼知道在保 / 90 天内到期 / 已过保 |
| 忘保养 | 按品类自动排期 → 打勾完成 → 自动排下一期 | 不用记周期，打开首页就能看到 |
| 坏了说不清 | 详情页一屏看到品牌、型号、购买日期、保修状态 | 报修时报得准，保内保外心里有数 |
| 家人反复问 | 手机浏览器打开链接 → 密码访问 → 首页看板 | 家人自己查，不用当人肉客服 |

**为什么是我们**：

- 拍铭牌直读，不用手抄型号——AI 是加速器，识别失败也能手填。
- 免安装 Web，家人打开链接就能用——不注册、不下载、不学新工具。
- 保修 + 保养一体——不是单纯的记录簿，是「该做什么」的看板。

**边界**：不做维修派单，不做智能家居控制，不做购物导购——只管家电的保修和保养。故障排查是下一步（AI 助手），不是第一版。

## 4. 三问自检

| 检查项 | 不合格的样子 | 本项目的答案 |
|---|---|---|
| 用户具体吗 | 「所有家庭」 | 有 5 台以上家电、有人管售后的家庭 |
| 痛苦真实吗 | 「用户想要一个管理工具」 | 找不到发票、猜保修、忘保养、被问住 |
| 价值一句话吗 | 「AI 赋能家电全生命周期管理」 | 拍一张铭牌，30 秒建档；保修和保养打开就知道 |

---

## 5. 收尾

> 买家电是一瞬间的事，养家电是十几年的事——homeplate 替家里记住这十几年。
