# 墨刀原型制作提示词（2026-10-17）

> 使用方式：先贴【全局设定】建立项目，再逐页贴【页面提示词】生成。每页提示词都可独立粘贴到墨刀 AI。

## 全局设定（先贴这段）

```
帮我做一个"家电档案管家"手机应用的高保真原型，共 14 个页面，375×812 手机尺寸。
产品名称：homeplate · 家电保养与维修助手。目标用户：中国普通家庭（含中老年）。
设计语言：
- 主色 #3D6DF2（蓝），警示色 #FF7A45（橙），成功色 #1FAF6B（绿），失效色 #8A93A5（灰）
- 页面背景 #F5F6F8，卡片纯白圆角 12px，浅阴影
- 中文字体 PingFang SC / 思源黑体；标题 22px 粗体，区块标题 15px，正文 14px，辅助文字 12px
- 顶部导航：左侧返回箭头 + 居中标题，右上角可有"编辑"等文字操作

- 设备图标用 MDI 线性图标风格，每个品类有专属图标（空调/冰箱/洗衣机等）
- 支持深色模式（背景 #12151C，卡片 #1E222B）——只做首页和设备详情页的深色变体即可
所有页面底部保留 20px 以上安全区。页面之间要有真实的跳转关系。
```

## 墨刀操作顺序建议

1. 先贴全局设定 + 页面 1/3/4（首页/确认页/详情页——核心三页，确认风格对不对）
2. 再贴页面 2/5/6/7（建档和两大记录功能）
3. 最后贴 8-14（提醒/家庭/统计/设置/登录/引导）
4. 深色模式只需做首页和设备详情两页变体，验证配色即可
5. 页面间连线：首页→详情（点卡）、首页→拍摄（点+）、详情→保养/维修/AI助手、我的→各设置页
