> 前提：对标"内容借鉴"——《新家管家》（App Store，独立开发者 Jie Xiang，v1.0.9，免费+订阅，本地存储+iCloud 同步）验证过的功能清单，逐项对照 homeplate 当前实现（v0.6.1+今日 3 个功能 commit）。

## 二、差距排序与工作量

**按新家管家验证过的用户价值排序：**

1. **维修记录与费用**（差距 #3）——四大主功能之一，完全空白。建议下一步就做：
   - 新表 `repair_records`（设备外键/日期/故障描述/处理方式/费用/备注）
   - 详情页"维修记录"区块 + 添加表单 + 编辑/删除（复用今天保养任务 CRUD 的模式）
   - 详情页费用小计（"累计维修 ¥xxx"）
   - 首页卡片可显示"维修 N 次"
2. **家庭优先级排序**（差距 #4）——把排序键从单一"保修到期"升级为：逾期保养任务 → 30 天内保养 → 即将过保 → 其余按保修到期。数据模型已支持，纯 pages.py 排序键改动。
3. **推送提醒**（差距 #10）——Web 限制下选低成本方案（Server酱微信推送 或 邮件），先做"保修到期前 7 天 + 保养逾期/当天"两类。
4. **深色模式**（差距 #7）——四页配色改 CSS 变量 + `prefers-color-scheme`，或 Tailwind `dark:` 类。
5. **收据/凭证照片**（差距 #11）——照片存档机制已就位，加一个"凭证"上传入口与 tab。

**不需要抄的**：订阅制（实训不收费）、iCloud（我们有等价物）、纯本地存储（路线不同）。

## 三、我方已有而对方没有的（保持住）

- **AI 拍铭牌直读建档**（对方文案无此能力）——这是"单台 ≤30 秒"验收标准的根基；
- **保养任务可编辑**（对方未说明，我们今天已做）；
- **免安装**（对方 iOS 17+ only，我们任何手机浏览器）；
- **删除保护、限速、照片可收起**等细节。
