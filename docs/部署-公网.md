## 一、先做选择题

三条路，选一条走，别混着来。

| | B 临时隧道 | A 云服务器 | C 托管平台 |

| 自己电脑关机后还能访问 | **不能** | 能 | 能 |

## 二、上线前必须知道的 7 件事（这个项目特有的坑）

| # | 事情 | 不处理的后果 |
| --- | --- | --- |
| 1 | `run.py` 里 `reload=True` | 生产环境开 reload 会监视文件、吃内存、随机重启，**必须换启动命令** |
| 2 | `templates` / `static` 用的是相对路径 | 用 systemd 启动时工作目录不对 → 首页直接 500（TemplateNotFound） |
| 3 | `requirements.txt` 没写版本号 | 服务器装到另一套版本，模板渲染/中间件行为可能变，**按下面的实测版本锁死** |
| 4 | MySQL 放在哪 | 服务器上的 `.env` 还写 `localhost:3306` 就连自己的库，必须重配 |
| 5 | Nginx 默认只允许 1MB 请求体 | 上传铭牌照片直接 **413**，必须调 `client_max_body_size` |
| 6 | 中国大陆机房 80/443 要 ICP 备案 | 未备案访问会被拦。**中国香港/海外机房免备案**，演示首选 |
| 7 | 图片只读进内存、不落盘 | 好消息：**不需要对象存储、不需要持久化盘**，省一笔 |

### 本机实测版本（服务器照这个装）

```text
python 3.12.7
fastapi 0.143.2
starlette 1.8.0
uvicorn 0.54.0
sqlalchemy 2.1.4
jinja2 3.1.6
openai 3.31.0

```

> 附注：`/api/recognize` 是 `async def` 里直接调同步的 `recognize_nameplate()`，一次识别会把事件循环堵住。多人同时拍会串行排队。部署时开 `--workers 2` 能缓解，彻底解决要把识别丢进线程池——这次先不动代码。

## 三、路线 A：云服务器部署

目标形态：

```text
浏览器 ──HTTPS/80,443──> Nginx ──127.0.0.1:8000──> uvicorn ──127.0.0.1:3306──> MySQL
```

只有 Nginx 暴露在公网，uvicorn 和 MySQL 都只听本机。

### 步骤 0：买机器与域名

**服务器**（任选，1 核 2G 起步够用）：

- 腾讯云轻量应用服务器 → **中国香港**节点，2 核 2G 3M，约 24–30 元/月，**免备案**
- 阿里云轻量应用服务器 → **中国香港**节点，同价位，免备案
- 想用国内节点（上海/北京/广州）：便宜些，但**必须 ICP 备案**（7–20 天），要域名

系统镜像选 **Ubuntu 24.04 LTS**（22.04 也行）。

**域名**（可选）：

- 不买域名：直接用 `http://服务器IP:8000` 访问，能跑，但浏览器标"不安全"，链接丑
- 买域名：`.top` / `.xyz` 首年十几块，解析 A 记录到服务器 IP。**中国香港节点无需备案**，可直接签 HTTPS

**安全组 / 防火墙放行**：22（SSH）、80、443。
**千万别放行 3306 和 8000** —— 那是把数据库和裸服务直接送到公网上。

### 步骤 1：登录服务器

在你电脑的 PowerShell 里执行：

```powershell
# 登录服务器；把 IP 换成你买的机器的公网 IP。首次会问 yes，输密码
ssh root@你的服务器IP
```

> 首次登录后建议改密码、建普通用户。演示项目先用 root 也能跑，但要知道这是欠账。

### 步骤 2：把代码传上去

服务器是干净的，只有两种方式拿到代码：从 GitHub 拉，或从本机传。

**方式一：从 GitHub 拉（推荐，你的仓库已经推上去了）**

服务器的 bash 里执行：

```bash
# 装 git（新机器可能没有）
apt update && apt install -y git

# 把仓库克隆到 /opt/homeplate；仓库是私有的话要先配 token 或 deploy key
git clone https://github.com/Echo2580/homeplate.git /opt/homeplate

# 看一眼文件到齐没有
ls /opt/homeplate
```

**方式二：从本机打包上传（仓库私有又懒得配 token 时用）**

本机 PowerShell：

```powershell
# 只打包 git 里已提交的文件，自动排除 .venv、测试图片、原型、.idea
cd D:\AI实训project\小组项目\ai家电保养与维修助手
git archive --format=tar.gz -o "$env:TEMP\homeplate.tar.gz" HEAD

# 上传到服务器 /tmp
scp "$env:TEMP\homeplate.tar.gz" root@你的服务器IP:/tmp/
```

服务器 bash：

```bash
# 建目录并解压
mkdir -p /opt/homeplate && tar -xzf /tmp/homeplate.tar.gz -C /opt/homeplate && ls /opt/homeplate
```

> 注意：`.env` 被 `.gitignore` 挡住了，**不会跟着代码走**，第 5 步要手动建。

### 步骤 3：装 Python 环境

服务器 bash：

```bash
# 装 Python 3.12 + 虚拟环境工具 + 编译依赖
apt install -y python3 python3-venv python3-pip build-essential libssl-dev default-libmysqlclient-dev

# 确认版本（要 >= 3.10）
python3 --version

# 在项目里建虚拟环境
cd /opt/homeplate && python3 -m venv .venv

# 升级 pip（走清华源，国内几秒）
.venv/bin/pip install -U pip -i https://pypi.tuna.tsinghua.edu.cn/simple

# 装项目依赖（同样走清华源）
.venv/bin/pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

装完核对关键版本是否与本地一致：

```bash
# 三条版本号应分别接近 0.143 / 1.8 / 0.54
.venv/bin/python -c "import fastapi,starlette,uvicorn;print(fastapi.__version__,starlette.__version__,uvicorn.__version__)"
```

> 版本差太多就锁版本：把 `requirements.txt` 里的包名改成 `fastapi==0.143.2` 这种写法再重装。

### 步骤 4：建 MySQL 库

服务器 bash：

```bash
# 装 MySQL 服务端
apt install -y mysql-server

# 确认它活着（应显示 active (running)）
systemctl status mysql --no-pager

# 进 MySQL 控制台
mysql
```

MySQL 控制台里执行（**把密码换成你自己的强密码，别用 123456**）：

```sql
-- 建库，强制 utf8mb4（中文品类名必须有）
CREATE DATABASE homeplate CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 建专用账号，只允许本机登录
CREATE USER 'homeplate'@'localhost' IDENTIFIED BY '换成你的强密码';

-- 授权
GRANT ALL PRIVILEGES ON homeplate.* TO 'homeplate'@'localhost';
FLUSH PRIVILEGES;

-- 退出
EXIT;
```

确认 MySQL 只听本机：

```bash
# 输出应该是 127.0.0.1:3306，如果看到 0.0.0.0:3306 说明暴露了，要改 bind-address
ss -lntp | grep 3306
```

### 步骤 5：写 `.env`

服务器 bash：

```bash
# 在项目根目录建配置文件
nano /opt/homeplate/.env
```

粘进去（**换成真实值**）：

```env
# 数据库：主机写 127.0.0.1，账号密码用第 4 步建的
DATABASE_URL=mysql+pymysql://homeplate:你的强密码@127.0.0.1:3306/homeplate?charset=utf8mb4

# 识别模型：DeepSeek 或阿里百炼，三行对应换
AI_API_BASE=https://api.deepseek.com
AI_API_KEY=sk-你的真实Key
VISION_MODEL=deepseek-flash

# 公网必须设！这就是整站的访问密码，用户名随便填，密码填这个
ACCESS_PASSWORD=换成你的演示密码
```

`nano` 保存：`Ctrl+O` → 回车 → `Ctrl+X`。

锁权限，防止别的用户读到密钥：

```bash
# 只有 root 能读
chmod 600 /opt/homeplate/.env
```

> **`ACCESS_PASSWORD` 一定要设。** 不设的话，任何扫到这个 IP 的人都能往你库里塞设备、还能免费刷你的大模型额度。Basic Auth 会覆盖页面和 `/api/*`，只有 `/healthz` 放行。

### 步骤 6：建表 + 手工验一次

服务器 bash：

```bash
# 建表（幂等，跑几次都没事）
cd /opt/homeplate && .venv/bin/python -m app.init_db

# 前台直接起一次服务，先不托管，方便看报错
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
```

另开一个终端窗口（服务器 bash）验证：

```bash
# 健康检查：应返回 {"app":"homeplate","status":"ok","database":"ok"}
curl -s http://127.0.0.1:8000/healthz

# 首页：应返回 401（因为设了 ACCESS_PASSWORD，这是对的）
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8000/

# 带密码访问首页：应返回 200
curl -s -o /dev/null -w "%{http_code}\n" -u "任意用户名:你的演示密码" http://127.0.0.1:8000/
```

`database` 是 `down` 就回去查 `.env` 里的账号密码和 `mysql` 服务状态。
验证完 `Ctrl+C` 停掉前台进程。

### 步骤 7：systemd 托管（开机自启 + 崩了自动拉）

服务器 bash：

```bash
# 创建服务单元文件
nano /etc/systemd/system/homeplate.service
```

内容（`WorkingDirectory` 这一行是关键，删了必 500）：

```ini
[Unit]
Description=homeplate FastAPI service
After=network.target mysql.service
Wants=mysql.service

[Service]
Type=simple
User=root
# 必须是项目根目录：templates/ 和 static/ 用的是相对路径
WorkingDirectory=/opt/homeplate
# 只用 127.0.0.1 监听，外部流量统一走 Nginx
ExecStart=/opt/homeplate/.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 2
Restart=always
RestartSec=3
Environment=PYTHONUNBUFFERED=1

[Install]
WantedBy=multi-user.target
```

启动并设开机自启：

```bash
# 重载 systemd 配置
systemctl daemon-reload

# 启动服务
systemctl start homeplate

# 设开机自启
systemctl enable homeplate

# 看状态，应为 active (running)
systemctl status homeplate --no-pager

# 实时看日志，Ctrl+C 退出
journalctl -u homeplate -f
```

> `--workers 2` 对应"识别会阻塞事件循环"那个问题，两个进程能各接一个识别请求。
> `app.maintenance` 里没有常驻定时器，多 worker 不会重复跑任务，可以放心开。

### 步骤 8：Nginx 反向代理

服务器 bash：

```bash
# 装 Nginx
apt install -y nginx

# 写站点配置
nano /etc/nginx/sites-available/homeplate
```

内容（**先只用 80 端口，HTTPS 下一步加**）：

```nginx
server {
    listen 80;
    # 没有域名就写服务器公网 IP；有域名就写域名
    server_name 你的域名或IP;

    # 关键：默认 1MB，不改的话上传铭牌照片直接 413
    client_max_body_size 12M;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # 关键：AI 识别可能跑 30–60 秒，默认 60 秒会 504
        proxy_read_timeout 180s;
        proxy_connect_timeout 10s;
        proxy_send_timeout 180s;
    }
}
```

启用并重载：

```bash
# 建软链启用站点
ln -s /etc/nginx/sites-available/homeplate /etc/nginx/sites-enabled/

# 删掉默认站点，避免抢 80 端口
rm -f /etc/nginx/sites-enabled/default

# 检查配置语法，必须显示 successful
nginx -t

# 重载生效
systemctl reload nginx
```

现在用手机流量（**关掉 Wi-Fi，不用 Tailscale**）打开：

```text
http://你的服务器IP/
```

弹密码框 → 用户名随便填，密码填 `ACCESS_PASSWORD` → 应该看到首页。

**这一步通了，公网就已经算上线了**，只是还是 HTTP。下面再加 HTTPS。

### 步骤 9：上 HTTPS（有域名才做）

前提：域名 A 记录已指向服务器 IP，并且 `dig 你的域名` 能查到。

服务器 bash：

```bash
# 装 certbot 和 Nginx 插件
apt install -y certbot python3-certbot-nginx

# 自动申请证书并改写 Nginx 配置（会问邮箱、同意协议）
certbot --nginx -d 你的域名

# 验证自动续期（应显示 success 或不需要续期）
certbot renew --dry-run
```

certbot 会自动：
- 把 80 的 `server` 块改成 301 跳 HTTPS
- 新增 443 的 `server` 块
- 塞进去证书路径

**中国香港/海外节点**：这一步通常几分钟过。
**中国大陆节点**：域名必须先完成 ICP 备案，否则 Let's Encrypt 的 HTTP-01 校验会被拦，签不下来。

### 步骤 10：收尾三件事

```bash
# 1) 系统防火墙（如果云厂商镜像自带 ufw）
ufw allow 22/tcp && ufw allow 80/tcp && ufw allow 443/tcp && ufw --force enable

# 2) 确认 3306 / 8000 没有对外监听（应只看到 127.0.0.1）
ss -lntp | grep -E '3306|8000'

# 3) 数据库备份目录
mkdir -p /root/backup
```

备份命令（建议每天跑一次，先手工验证）：

```bash
# 导出整库到带日期的文件；把密码换成你的
mysqldump -u homeplate -p'你的强密码' --single-transaction homeplate > /root/backup/homeplate-$(date +%F).sql
```

> 想自动化就加一条 crontab：`0 4 * * * mysqldump ...`。演示项目手工备份也够。

## 四、路线 B：十分钟拿到公网链接（不动服务器）

适合"今晚就要发给老师看一眼"。缺点：**你的电脑必须开着、项目必须跑着**。

你已经装过 Tailscale，所以这条路几乎是白送的。

### B-1 Tailscale Funnel（最省事）

本机 PowerShell：

```powershell
# 开启公网转发：把本机 8000 暴露成 https://你的机器名.xxx.ts.net
& 'C:\Program Files\Tailscale\tailscale.exe' funnel --bg --https=443 http://127.0.0.1:8000

# 查看是否生效（应出现 Funnel on 字样和一个 https 地址）
& 'C:\Program Files\Tailscale\tailscale.exe' funnel status
```

拿到那个 `https://xxx.ts.net` 地址就能发给任何人，对方**不用装 Tailscale**。

```powershell
# 演示结束后关掉公网暴露（强烈建议关，别长期开着）
& 'C:\Program Files\Tailscale\tailscale.exe' funnel --https=443 off
```

> 说明：Funnel 走海外节点，国内访问速度一般，偶尔抽风。够"看一眼"，不适合正式答辩。
> 注意它和之前的 `serve` 不是一回事：`serve` 只有你自己网络内能看，`funnel` 才是公网。

### B-2 Cloudflare Tunnel（备选）

不想用 Tailscale 就用这个：

```powershell
# 装 cloudflared
winget install --id Cloudflare.cloudflared

# 起一个临时隧道，把 8000 端口暴露出去（无需注册、无需域名）
cloudflared tunnel --url http://127.0.0.1:8000
```

输出里会给你一个 `https://xxxx.trycloudflare.com` 地址。
**每次重启地址都会变**，且国内访问稳定性看运气。

## 六、故障对照表

| 现象 | 大概率原因 | 怎么查 |
| --- | --- | --- |
| 浏览器转圈最后超时 | 安全组没放行 80/443 | 云控制台看防火墙规则 |
| 502 Bad Gateway | uvicorn 没起来 | `systemctl status homeplate`、`journalctl -u homeplate -n 50` |
| 500 + TemplateNotFound | systemd 的 `WorkingDirectory` 写错 | 检查 `/opt/homeplate/templates` 是否存在 |
| 页面出来了但没样式/图标 | `static/` 没传全，或 Nginx 没放开 | `ls /opt/homeplate/static/js` |
| 上传照片 413 | `client_max_body_size` 没改 | `nginx -t` 后看配置文件 |
| 识别报 502 / 超时 | 服务器连不上模型 API，或 Nginx 超时太短 | `curl -I https://api.deepseek.com`；看 `proxy_read_timeout` |
| `/healthz` 里 `database: down` | `.env` 密码错、MySQL 没起 | `systemctl status mysql`；`.venv/bin/python -c "from app.database import engine;print(engine.connect())"` |
| 一直弹密码框输不对 | `ACCESS_PASSWORD` 里有空格/引号 | `cat -A .env \| grep ACCESS` |
| 域名打不开但 IP 能开 | DNS 没生效 / 备案没下来 | `dig 你的域名`；国内节点查备案状态 |
| 中文存进去变问号 | 库或连接不是 utf8mb4 | 建库语句里的 `CHARACTER SET utf8mb4` |

## 七、我建议改、但还没动的文件

以下三项会影响稳定性。**没你点头我不动代码**：

1. `requirements.txt` —— 加版本号锁定（如 `fastapi==0.143.2`），防止服务器装到不兼容版本
2. `run.py` —— 加注释说明「生产环境不要用这个入口」，或拆出 `run_prod.py`
3. `app/routers/recognize.py` —— 把同步识别调用丢进 `run_in_threadpool`，让并发识别不互相堵

要改哪条，说一声。
