# 同类型产品调研（2026-10-17）

> 目的：看清"AI 家电保养与维修助手"这个赛道有没有成熟产品、做到什么程度、我们的差异在哪。
> 方法：应用商店 listing 文案（经 iTunes Lookup API 获取）、GitHub API、公开报道。**未做安装实测**，价格/评分为 2026-10-17 时点值，商店文案可能夸大。

## 一、结论先说

1. **赛道已有成熟玩家，且不弱**：海外的 HomiHub 与 homeplate 几乎同构（拍铭牌建档 + 保修 + 保养提醒 + AI 问答）；国内有《新家管家》《Freedom Tools·家庭维护》等近亲。
2. **但一个空位仍然存在**：**面向中国家庭、中文、免安装 Web（链接即用）、拍照铭牌直读、保修+保养+维修记录一体化**的产品没有成熟形态。现有产品要么是英文 App（HomiHub/HomeLog），要么是 iOS 订阅制 App（新家管家），要么功能更轻（Warranty Keeper/Freedom Tools）。
3. **最大的警示**：美国 Centriq 是这条赛道最接近的标杆（拍标签→说明书/保修/配件/召回），据报 2025 年初关停、商店下架、域名失效。**"手册库 + 生态"这条路个人/小团队走不通**，轻量"档案 + 提醒"才有机会。

## 三、已退场的标杆：Centriq（必读案例）

- 能力：拍产品标签 → 说明书、保修信息、配件、召回提醒 + 维护提醒 + 资产清单。
- 结局：据 Itemlist 博客（2026-07 复核），Centriq 据报于 2025 年初关停，App Store listing 下架、域名失效，且无第一方公告留存。
- 启示：
  1. **手册/召回数据库需要持续数据合作**，个人/小团队做不了，别把它当核心；
  2. "记录家电"是低频需求，获客成本高——必须把单次使用做得足够省事（拍照即建档就是对的）；
  3. Centriq 关停后需求被拆成"手册维护"（Dib、HomeBeacon）和"物品清单"（Itemlist）两半，说明**产品定位要单一**，别想一个 App 全包。

## 五、对 homeplate 的启示（按优先级）

1. **补"维修记录/费用"**——新家管家、HomiHub 都把它当标配（ROADMAP 已列 v1.1）。
2. **补"到期提醒推送"**——HomiHub/新家管家/HomeLog 全都有；我们还没有，这是同型产品的**基本盘功能**，应优先于任何锦上添花。
3. **补"凭证/手册照片"**——HomiHub、Warranty Keeper、Freedom Tools 都存收据与手册；我们目前只有铭牌照片。
4. **导出/备份**——Freedom Tools 提供 CSV/PDF；我们 ROADMAP 有数据备份，应尽快落地（也是"家人长期用"的信任基础）。
5. **AI 问答**——HomiHub "instant answers"、iFixit FixBot、博西智能体都在做；我们放阶段 2，别现在碰。
6. **不碰**：手册库、召回数据、上门维修撮合（Centriq 的坑 + 重运营/重合规）。

## 六、定位建议（答辩/BP 可直接用）

> 不是"又一个家电管理 App"，而是**"中国家庭的家电档案 + 中文铭牌识别 + 免安装 Web"**——爸妈收到一个链接、输一次密码，拍张铭牌就能建档，打开就知道哪台该保养、哪台快过保。
