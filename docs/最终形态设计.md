# homeplate 最终完全形态设计（2026-10-17）

> 用途：墨刀原型制作的完整蓝图。所有页面、闭环、数据结构、交互一次想清楚。
> 定位锚点：中国家庭的家电档案管家——**拍一张铭牌建档，保修、保养、维修全周期管起来，到日子主动提醒家人**。
> 设计约束：手机浏览器 Web（免安装）、安卓为主、家人共用、深色模式支持。

## 一、产品哲学

买家电是一瞬间的事，养家电是十几年的事。完全形态的 homeplate 回答三个问题：

1. **这台家电是谁的、什么型号、还剩多久保修？**（档案）
2. **它什么时候该保养/该保修/该修了？**（主动提醒）
3. **坏了怎么办？**（AI 排查 → 维修记录沉淀）

所有功能都必须是一个闭环：入口 → 动作 → 结果 → 沉淀 → 下次触发。不做只进不出的"记录簿"。

## 二、六大闭环

### 闭环 1：建档（已有，强化）
拍照/相册 → AI 识别（名称/品牌/型号/序列号/品类）→ 确认页预填可改 → 保存 → 铭牌照片+凭证照片归档 → 自动挂保养模板 → 首页可见。
- 最终形态增加：**批量建档**（一次拍多台，队列识别）；**说明书/发票照片**同入口上传。

### 闭环 2：保修（已有，强化）
购买日期+保修期 → 三色状态 → 首页"家庭优先级"置顶 → **到期前 30/7 天推送** → 到期后提示"已过保，是否续保/记录换新" → 决策沉淀到档案。
- 增加：**续保记录**（延保服务录入，重新起算保修期）；**换新记录**（旧设备归档"已替换"而非删除）。

### 闭环 3：保养（已有，强化）
品类模板自动排期 → 到期/逾期提醒（推送）→ 详情页完成打勾 → 自动排下一期 → **保养历史**（每次完成时间、费用、照片）→ 统计页沉淀。
- 增加：**完成时记费用**（洗滤网 0 元/请师傅 80 元）；**保养照片**（前后对比，如滤网脏照）；**自定义模板**（我家净水器是 3 个月不是 6 个月）。

### 闭环 4：维修（新增，对标新家管家最大差距）
故障描述（文字/拍照）→ **AI 维修助手**给排查建议（基于品类+型号+症状，输出"自检步骤/是否需要师傅/预估费用区间"）→ 用户选择：自行解决 → 记一条维修记录（费用 0）；或叫师傅 → 维修记录（师傅电话/费用/凭证照片/保内还是保外）→ 维修历史沉淀 + **费用统计**。
- 闭环关键：**维修完回写保修状态**——保内维修成功保修继续；保外大修后提示"是否登记延保"。

### 闭环 5：提醒（新增，同型产品基本盘）
每天定时扫描 → 触发规则（保修剩 30/7 天、保养到期、保养逾期超 7 天、维修后 30 天回访）→ 推送（微信 Server酱 / 邮件 / 后续微信服务号）→ 推送里带**直达链接**（点开就是对应设备详情页，可一键"完成保养/我已处理"）→ 处理后停止推送。
- 闭环关键：**可处理、可静音、可回执**，不做只响不停的闹钟。

### 闭环 6：家庭协作（阶段 2，多账号）
创建家庭 → 邀请成员（微信扫码加入）→ 成员各自手机访问同一家庭 → 设备/任务共享 → 保养完成记录谁做的（"妈妈 10-17 清洗了滤网"）→ 家庭动态流（最近 30 天发生了什么）。
- 闭环关键：加入即能用，退出不丢数据，家庭成员无学习成本。

## 四、数据结构演进（最终形态）

```
family（家庭）── members（成员：微信openid/昵称/角色）
   └── device（设备：档案 + 铭牌照片 + 凭证照片[] + 说明书PDF?）
        ├── warranty_policy[]（保修期记录：原始 + 延保，最新一条生效）
        ├── maintenance_task[]（保养任务：模板或自定义，可编辑）
        │    └── maintenance_record[]（完成记录：时间/费用/照片/操作人）
        ├── repair_record[]（维修记录：故障/处理/费用/师傅/凭证/操作人）
        └── reminder_log[]（提醒回执：何时推的、推给谁、处理结果）
user_setting（推送渠道/规则/深色模式/勿扰时段）
```

关键设计：
- **记录与任务分离**：task 是"下次什么时候"，record 是"以前做过什么"——现在是混的（只有 last_done_at），最终形态要拆；
- **操作人**：所有 record 记 member_id，家庭协作的基础；
- **设备状态机**：在用 → 已替换/已卖/已坏（归档不删除，保留历史）。

## 五、视觉规范（延续现有，墨刀照做）

- 主色：#3D6DF2（蓝，操作/正常）；警示：#FF7A45（橙，临期/逾期）；成功：#1FAF6B（绿，在保/完成）；失效：#8A93A5（灰，过保/归档）
- 背景 #F5F6F8，卡片白底圆角 12px，阴影 0 1px 2px rgba(16,24,40,.04)
- 字体阶梯：页面标题 22px 粗 / 区块标题 15px / 正文 14px / 辅助 12px；输入框 16px（防安卓误触）
- 深色模式：背景 #12151C，卡片 #1E222B，文字 #E8EAEE，主色不变
- 设备图标：MDI 图标集，品类→图标映射延续现有规则
- 页面宽度 max 480px 居中，安全区适配，底部悬浮主操作按钮
