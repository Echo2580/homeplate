### 环境要点（新会话必读）
- MySQL：本地 `D:\mysql\`（服务名 MySQL80），客户端 `D:\mysql\bin\mysql.exe`，不在 PATH
- Python：项目 `.venv`（3.12.7），依赖见 requirements.txt；**openai 3.31 依赖 httpx2 而非 httpx**
- 启动：PyCharm 跑 `run.py`；**PyCharm 下 uvicorn reload 不生效，改 .py 必须手动重启**
- 识别供应商：.env 三变量（AI_API_BASE / AI_API_KEY / VISION_MODEL）可切换，当前 DeepSeek-flash，备选百炼 qwen-vl-plus（切回更快，配置在 .env.example 注释）
- 网络环境：校园网（WLAN 172.24.251.35/15）手机↔电脑直连被阻，**已用 Tailscale 解决，不要重蹈局域网排查覆辙**
- 安全提醒：Windows 防火墙曾被全部关闭（非本项目所为），后续应恢复并复测

### 协作规矩（用户既定）
- git：功能级 commit + 里程碑 tag（v0.x.0 递增），完工即推
- `.env`（含 MySQL 密码、AI key、访问密码）绝不进仓库
- 数据库迁移：新表用 init_db（create_all），改列要写 ALTER（参考 Day 2 的 purchase_date 迁移）
- 不确定的事先问再做；区分"已验证事实"与"用户口头反馈"
